Setup guide

Get a Google Client ID (~3 min)

  1. Go to console.cloud.google.com → create (or pick) a project.
  2. APIs & Services → Library → enable Google Sheets API.
  3. APIs & Services → OAuth consent screen → set it up (External, add your email as a test user if it stays in Testing).
  4. APIs & Services → Credentials → Create Credentials → OAuth client ID → type Web application.
  5. Under "Authorized JavaScript origins" add the exact URL you'll open this file from (e.g. your GitHub Pages URL, or http://localhost:8000 if testing locally). file:// won't work — camera + Google sign-in both need http/https.
  6. Copy the Client ID and paste it into the ⚙ settings panel above.
